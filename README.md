# Sky-reports — отчёты и конфиг «Небесного прилива»

- `reports/latest.txt` — последний полный отчёт игры (раз в 5 мин, при сворачивании, при метке).
- `reports/session0..4.txt` — последний отчёт каждой из 5 последних сессий (по кругу).
- `reports/mark0..9.jpg/.txt` — 10 последних меток: снимок экрана + отчёт (автометки и ручная «МЕТКА»).
- `config/config.json` — баланс без пересборки: игра читает при запуске (и по «конфиг заново» в меню тестера).
  Поля и значения по умолчанию — `Assets/_Project/Scripts/Core/RemoteConfig.cs` в репозитории Sky.
