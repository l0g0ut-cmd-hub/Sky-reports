# Sky-reports — отчёты и конфиг «Небесного прилива»

- `reports/latest.txt` — последний полный отчёт игры (раз в 5 мин, при сворачивании, при метке).
- `reports/session0..4.txt` — последний отчёт каждой из 5 последних сессий (по кругу).
- `reports/mark0..9.jpg/.txt` — 10 последних меток: снимок экрана + отчёт (автометки и ручная «МЕТКА»).
- `config/config.json` — баланс без пересборки: игра читает при запуске (и по «конфиг заново» в меню тестера).
  Поля и значения по умолчанию — `Assets/_Project/Scripts/Core/RemoteConfig.cs` в репозитории Sky.
- `config/commands.json` — удалённые команды в запущенную игру (`{"id", "expires", "cmds": [...]}`), игра опрашивает раз в 15 с,
  итог — `reports/ack.txt`. Список команд: `help` (DevCommands.cs). `reports/alive.txt` — игра запущена сейчас (раз в 2 мин).
- `reports/crash.txt` — причина аварийного завершения прошлого запуска (Android) + хвост logcat.
- `reports/bench.txt` — автозамеры по сборкам (сам при первом запуске новой сборки).
- `reports/replay.bin` — повтор боя (15 мин, 2 Гц), видео: `tools/replay.py` в репозитории Sky.
- Релиз `apk` — последняя сборка; игра сама предлагает её скачать.
